# Diagram sources

The `.drawio` files and `spotter-overview.svg` one folder up are generated by these scripts from the Paddock diagram kit
(`paddock/diagrams/tools`, expected as a sibling checkout next to `spotter`). The `.drawio` files stay editable in draw.io;
re-running a script overwrites its diagram. The scripts are development tooling (Node); nothing here ships in the app.

```sh
node docs/diagrams/src/c4.mjs         # one diagram family: c4, c43, state, seq, cls, deploy, overview
scripts/export-diagrams.sh            # then export SVG (and the git-ignored 2x PNGs); needs draw.io desktop
```

| Script | Writes |
|---|---|
| `c4.mjs` | `c4-1-context`, `c4-2-containers` |
| `c43.mjs` | `c4-3-engine` |
| `state.mjs` | `uml-state-watch` |
| `seq.mjs` | `uml-seq-check-release`, `uml-seq-rendered-page` |
| `cls.mjs` | `uml-class-ports` |
| `deploy.mjs` | `uml-deployment-windows`, `-macos`, `-linux` |
| `overview.mjs` | `spotter-overview.svg` (hand-drawn, one file for light and dark) |
